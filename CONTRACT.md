## Backend ownership and API
Backend owns `internal/server/**` ONLY. Package `server` exposes:
```go
type NetworkAddress struct { Name string `json:"name"`; IP string `json:"ip"` }
type Config struct {
 DeviceName string
 StorageDir string
 Port int

 ClipboardWrite func(string) error
 OpenFolder func() error
}
func New(Config) (*Server,error)
func (*Server) Handler() http.Handler
func (*Server) Close() error
func (*Server) JoinURL() string
func (*Server) UpdateAddresses([]NetworkAddress)
```
Backend does NOT own asset embedding; main dispatches /api/, /ws, /s/ through backend and `/`/assets through backend authentication middleware plus embedded assets. To simplify integration expose `func (*Server) SetAssets(http.Handler)` and serve this handler as authenticated fallback. `/` unauthenticated remote returns a friendly Indonesian 401 HTML explaining scan QR. Host root bootstrap allowed only actual loopback requests with localhost/127.0.0.1 Host; use host cookie random separate from peer token. Host privileged APIs require loopback plus cookie. Protect host and peer requests against cross-site origin and DNS rebinding. Use allowed hostnames localhost, loopback, detected LAN IPs. No CORS wildcard. Never trust X-Forwarded-For. Cryptographic session token >= 24 random bytes. HttpOnly SameSite cookie. `/s/{token}` validates token and sets peer cookie then redirects `/`. No remote privilege even when forged device name/id.

JSON state (GET `/api/state`, and WebSocket messages `{type:"state",state:<same>}`):
```json
{"role":"host|peer","deviceName":"hostname","sessionId":"public generation id","joinUrl":"host only URL","qrUrl":"/api/qr","addresses":[{"name":"Wi-Fi","ip":"192.168.1.25","url":"host only join URL"}],"storagePath":"host only","texts":[{"id":"opaque","text":"string","sender":"Laptop/iPhone","createdAt":"RFC3339"}],"files":[{"id":"opaque","name":"photo.jpg","size":123,"mime":"image/jpeg","sender":"iPhone","createdAt":"RFC3339","downloadUrl":"/api/files/opaque"}],"devices":[{"id":"opaque","name":"iPhone","connectedAt":"RFC3339"}],"settings":{"autoCopy":false}}
```
Arrays newest first. No fake history/devices. `addresses`, `joinUrl`, `qrUrl`, `storagePath` omit or empty for peers. WebSocket `/ws?id=<clientUUID>&name=<deviceLabel>` same cookie; accepts hello if needed; tracks peer connections, excludes host from peer count, removes after disconnection, disconnect session rotation. Frontend stores browser UUID in sessionStorage and sends `X-Device-ID` in API requests. Sender classification must come from server role; device label bounded/escaped.

Endpoints use JSON error `{error:"human Indonesian message"}` and HTTP error status:
- POST `/api/text` body `{text}` (max 1MiB); appends history capped 100; optional autoCopy for peer inbound only. Return created entry.
- DELETE `/api/texts` HOST clears text history only (confirm UI).
- POST `/api/files` multipart `files` one file per frontend request, streaming to temp then atomic final filename in StorageDir. No original-name traversal/overwrite, support Unicode names, collision-safe names, partial cleanup on abort. Limit 10GiB per file, do not read file bytes all into memory. Return `{files:[file]}`. Metadata may remain session-only; keep completed disk files across restarts.
- GET `/api/files/{id}` authenticated streaming download, safe Content-Disposition; support range through ServeContent. No frontend file deletion required.
- GET `/api/qr?ip=<optional detected IP>` HOST PNG for matching joinURL, no cache. No network interface -> localhost fallback QR + frontend warning.
- POST `/api/settings` HOST body `{autoCopy:bool}` -> state.
- POST `/api/session/rotate` HOST -> new state; clears devices/disconnects peers, invalidates old token; host persists.
- GET `/api/clipboard` HOST -> `{text}`; clipboard unavailable -> useful error.
- POST `/api/open-folder` HOST -> `{ok:true}`.
- GET `/api/health` public only `{ok:true}` no secrets.
